Dúvidas

Não. O sistema funciona no plano grátis do Notion.

Sim. O kit vem pronto, com exemplos, e cada área tem uma videoaula mostrando o que fazer, pelo celular. Se travar, chama a gente no WhatsApp.

Sim, pelo app do Notion, com atalhos para registrar na hora.

Não. Você paga uma vez e o sistema é seu.
